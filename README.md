# 🎧 Context Audio Assistant

> **AI-powered content interaction through natural language questions and spoken answers**

Context Audio Assistant is an intelligent browser extension and web application that transforms how you consume digital content. Ask questions about any webpage, PDF, or article in natural language, and receive instant answers read aloud.

**Tech Stack:** Python 3.8+ | FastAPI | Groq LLaMA3 | MIT License

## ✨ Features

- 🌐 **Browser Extension** - Automatically captures content from any webpage
- 📄 **Multi-Format Support** - Load PDFs, URLs, or paste text directly
- 💬 **Natural Language Q&A** - Ask anything about the loaded content
- 🔊 **Audio Responses** - Answers are spoken aloud using text-to-speech
- 🎤 **Voice Input** - Ask questions hands-free with speech recognition
- ⚡ **Lightning Fast** - Powered by Groq's LPU for sub-2-second responses
- 🎨 **Modern UI** - Professional glassmorphism design with gradient backgrounds
- 🔒 **Privacy-First** - All processing happens locally
